# Neo4j-Social-Network

Welcome to the **Neo4j Social Network Project**! 🎉  

This project demonstrates how a **graph database** like Neo4j can efficiently model and query **connected data**. Using nodes, relationships, and properties, I simulate a simple social network where users can be follow each other and to like each others posts.

To run the project:
1. docker compose up
2. poetry run start 

If you need some mock data: 
-> poetry run mock
